## 규칙 요약 (프롬프트에 항상 넣을 것)
- 윤곽선 없는 평면 에디토리얼 화풍, 옅은 종이 질감, 크림·샌드·올리브·테라코타(+소량 머스터드/네이비).
- 창문 빛이나 화면 밖 물체가 비치는 그림자는 금지, 사물 바로 아래 작은 접지 그림자는 허용.
- 소품은 1~4개로 절제, 글자·숫자·로고 금지, 투명 배경(`background: transparent`).
- 레퍼런스의 로고·상표·캐릭터(포인트오브뷰 뉴스보이, 사과 등)는 복제하지 않는다.

## 레퍼런스
- 화풍 레퍼런스: `O's references/pointofview references/`(img.zip 포함)와 Figma 01 페이지 `A07 아바타 원본 (보관)`(76:3417), 03 페이지 일러스트 시트.
- 이번 세션에서 힉스필드에 올린 참조 이미지는 위 원본의 크롭·변환본이며 폴더에는 복사하지 않았다.

## 운영 메모
- 힉스필드 작업 공간이 바뀌면(요금제 변경 등) 이전에 올린 참조 이미지가 보이지 않으므로(404) **참조를 다시 업로드**해야 한다.
- 동시 작업은 4건 안팎, 요청이 몰리면 429가 난다(4~5건씩 나눠 제출). 배경 제거는 1크레딧 안팎.
- Figma 안에서는 외부 주소 이미지를 못 불러오므로, Figma MCP `upload_assets`의 업로드 URL에 파일 바이트를 POST한다(raw bytes + Content-Type이면 레이어 이름 유지).
