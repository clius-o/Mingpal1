## 실제 예시 콘텐츠

- 선택한 문장: “Is there a small routine that makes you feel at home?”
- 내 생각: “딸이랑 요리했는데 엉망이었지만 재밌었어.”
- 제안: “I cooked with my daughter. We made a mess, but we had fun.”
- 설명: “딸과 요리했다는 이야기와 즐거웠던 마음을 함께 담았어요.”

이전 콘셉트의 “We made a mess, but we had fun.”만 삽입하면 딸·요리라는 맥락이 빠진다. 제안이 독립 문장으로 들어가도 사용자의 핵심 경험을 보존하도록 보완한다. ‘매주’, ‘집처럼 편안했다’ 등 말하지 않은 사실과 감정을 추가하지 않는다.

## 상태 전이에서 빠뜨리지 않을 규칙

1. 생성 요청은 입력 버전과 묶는다. 생성 중 수정하면 이전 요청을 무효화하고, 새 입력에 대해 사용자가 다시 실행한다.
2. 결과를 받은 후 ‘생각 수정’을 누르면 제안의 삽입 행동을 해제한다. 수정 전 제안을 새 입력의 결과처럼 사용하지 않는다.
3. 삽입은 사용자가 확인한 현재 초안·위치에 한 번만 적용한다. 동기화 충돌이면 삽입을 보류하고 초안 복구와 표현 복사를 제공한다.
4. ‘되돌리기’는 해당 삽입 작업만 취소한다. 이후 작성 내용까지 과거 초안으로 되돌리지 않는다. 삽입 구간을 사용자가 수정했다면 즉시 자동 삭제하지 않고 삭제할 구간을 확인시킨다.
5. 도움을 닫아도 이번 작성 세션의 입력은 보존한다. 종료 후 장기 저장을 약속하지 않는다. 초안 저장 상태와 도움 입력 보존은 별개다.
6. 캐릭터 오류 표정·애니메이션만으로 상태를 전달하지 않는다. 상태 문구와 실행 가능한 버튼을 함께 둔다.

## 시각 검수 통과 기준

- 한국어/영어 본문, 버튼 문구, 하단 안전 영역에 잘림·겹침이 없다.
- 키보드 화면의 입력 커서와 실행 버튼이 보이며 긴 입력은 내부 또는 페이지 스크롤로 접근된다.
- 200% 글자는 단순 화면 확대가 아니라 실제 텍스트 재배치로 검수한다.
- 색상 대비는 최종 토큰으로 측정한다. 정적 시안만으로 접근성·성능 검증 완료라고 표시하지 않는다.
- 모션 줄이기에서는 캐릭터가 정지해도 처리·완료·실패 상태를 이해할 수 있다.
- 사진 아바타, 오디오 아이콘, 감정 점수, 강제 장기 기억, 자동 삽입·발송이 없다.
