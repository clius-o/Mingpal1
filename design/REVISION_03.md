## 완료

- 이전 11개 상태 화면을 보존하고 오른쪽에 대표 3화면을 별도로 제작했다.
- 생각 입력(22:106), 표현 제안(22:146), 편지 복귀(22:190).
- 독자적 입체 캐릭터 자산을 생성하고 Figma 컴포넌트(22:99)로 배치했다. 입력 210px, 제안 84px, 작성 도구 32px. 원본은 companion-3d-v2.png.
- 캐릭터가 들어 있던 반복 배경 카드를 제거했다. 제안 화면의 사용자 생각도 열린 배경으로 바꾸어 영어 제안 면이 중심이 되게 했다.
- 한국어 제목 25/34, 영어 제안 24/35, 편지 본문 18/30으로 조정했다. 글꼴은 Noto Sans KR. 실제 영문 줄바꿈으로 검수했다.
- 닫기/뒤로 아이콘을 기존 프로토타입의 SVG 경로로 교체하고 44px 조작 영역에 배치했다.
- 작성 화면의 영어 도움을 보내기 전 확인 위로 이동했다. 삽입된 문장의 강조와 되돌리기는 유지했다.

## 검증

- 대표 보드에 TEXT 38, FRAME 40, VECTOR 3, INSTANCE 7. 이미지가 들어간 노드는 캐릭터 인스턴스 3개뿐이며 전체 UI를 이미지로 넣지 않았다.
- 전체 화면 스크린샷 검수 중 결과 화면의 캐릭터 행 높이가 240px로 남아 하단 버튼이 잘리는 오류를 발견했다. 84px로 수정한 후 세 화면 전체를 다시 검수했다.
- 세 화면 높이는 844px. 수정 후 결과 화면의 마지막 행동 영역 끝은 정확히 844px다.
- 보조 글자 #636D66 / 배경 #F5F6F5 대비 4.96:1, 흰 면 대비 5.37:1. 기존 강조 #4F7B71 / 배경은 4.40:1로 일반 글자 기준에 미달하여 공유 강조 토큰을 #446E65로 어둡게 수정하고 다시 시각 검수했다. 흰 버튼 글자 / 검정 버튼 대비는 14.80:1.

## 한계 및 다음 작업

캐릭터는 입체 외형 탐색안이다. 이전 벡터보다 재질과 조명은 개선됐지만 큰 눈과 머리 비율은 귀여운 인상을 만든다. 성인 타깃 적합성, 독자성, 여러 표정·동작의 일관성은 아직 검증하지 않았다. 원본 PNG는 1,091,963 bytes이며 제품용 크기별 리소스 최적화 전이다.

키보드·320px·큰 글자는 이전 상태 보드의 검토안이다. 이번 정밀화 스타일을 해당 상태에 확장하는 작업과 읽기 선택 메뉴·초안 충돌 상세 설계가 남아 있다. 실제 키보드, 보조 기술, 모션, 성능 검증은 구현 후 진행한다. 제품 코드 및 클릭 프로토타입은 변경하지 않았다.
