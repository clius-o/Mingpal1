# 제안서: '둘만의 공간' → '수첩' 이름 변경과 M03 구조 변경 반영

작성: 2026-11-03 · 상태: **1~7번 모두 반영함 (2026-11-03, 사용자 "모두 반영" 지시)**. §4 "결정이 필요한 것"은 문서에 정하지 않고 그대로 남김
근거 화면: Figma '01 콘셉트 4안' 페이지의 1-4D(`222:1000`, 한 줄 카드 안)와 1-4E(`222:1070`, 수첩 화면). 사용자가 "수첩"을 직접 선택했고, 한 줄 카드 + 별도 화면 구조를 "추천대로"로 승인했습니다.

바뀐 것은 두 가지입니다.
1. 이름: '둘만의 공간' → '수첩'. 연인·부부에게 쓰는 말 같아서 앱의 조용한 말투와 맞지 않는다는 사용자 지적에 따른 변경입니다.
2. 구조: 친구별 기록(M03) 안에 시작 시점·우표·다음에 물어볼 이야기를 모두 두던 것을, M03에는 **'수첩' 한 줄 카드**만 두고 자세한 내용은 **별도 화면(제안 ID: M03a)** 으로 옮깁니다. M03 첫 화면에서 편지 목록이 더 많이 보이게 하려는 변경입니다.

## 2. M03a 전문 제안 (SCREEN_SPEC.md에 추가할 문장)

> ### M03a 수첩
>
> 상단: 뒤로 / ‘수첩’ / 부제 ‘{친구 이름}와 나’. 위에서 아래로: ‘시작’(편지를 나누기 시작한 시점과 두 도시) → ‘주고받은 우표’ → ‘다음에 물어볼 이야기’.
> ‘다음에 물어볼 이야기’는 사용자 전용이며 항목마다 ‘수정’·‘삭제’를 제공한다. 삭제는 확인 후 실행한다.
> 항목은 읽기 화면의 문장 선택 메뉴 ‘다음에 물어보기’(Q01)로만 추가한다. 이 화면 아래쪽에 추가 방법을 한 줄로 안내한다. AI가 자동으로 추가하지 않는다.
> 편지 수·단계별 해금·‘다음 우표까지’는 표시하지 않는다. 우표 단위(도시·나라·계절)는 [미정].
> 항목이 없을 때의 문구는 [미정].
